# Security Policy

## Supported Versions

Only the latest release of this package receives security fixes.

| Version | Supported |
|---------|-----------|
| 4.x     | ✅        |
| < 4.0   | ❌        |

## Reporting a Vulnerability

Please report security vulnerabilities privately using [GitHub's private vulnerability reporting](https://github.com/alperenersoy/filament-export/security/advisories/new) rather than opening a public issue.

Include as much of the following as you can:

- A description of the vulnerability and its impact
- Steps or code to reproduce it
- The affected version(s)

You can expect an initial response within a few days. Please keep reports confidential until a fix has been released.
